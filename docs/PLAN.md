## Как работает подключение (проверенная связка)

- VLESS + XHTTP + REALITY, mode `auto`, маскировка vk.com, fp firefox, порт 2083 (NL, LV, SE), Москва через 2087.
- Фрагментация первого пакета: куски 100–200 байт, пауза 1 мс.
- Ноды: Xray 25.6.8. Клиент Xray 26.3.27 проверен по всем странам.

## Архитектура

```
Интерфейс (Flutter, общий для Android / Windows / macOS)
        ↓
Слой подключения: подписка, выбор страны, пинг, правила маршрутизации
        ↓
Адаптер ядра Xray   |   (будущий адаптер второго ядра)
        ↓
Android: Xray в процессе приложения + VpnService (TUN-вход Xray)
Windows: tek-core.exe: системный прокси или «весь трафик» через wintun
macOS:   tek-core: системный прокси или «весь трафик» через utun (с паролем администратора)
```

## Этапы

1. Каркас: Flutter-проект, разбор подписки, генерация конфига Xray, тесты.
2. Android: туннель, APK.
3. Windows: установщик + zip.
4. macOS: .dmg (Apple Silicon + Intel).
5. Логотип и дизайн в стиле минимализма.
6. Вход по почте, deeplink, автообновление приложения.

Сборки делает GitHub Actions, готовые файлы лежат в Releases.
